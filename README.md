# NVIDIA DGX Spark notes

A log of getting started with an NVIDIA DGX Spark, written by a developer who is experienced with Java and Ubuntu but new to running LLMs locally. The notes are for my own reference, and for anyone else who is starting out with the same machine.

## Contents

0. [Unboxing](0-Unboxing.md): what the Spark is, what is in the box, first power-up, first-boot setup, and a first look at the machine.
1. [Remote access](1-Remote-access.md): SSH keys and an alias, for working with the Spark headless.
2. [Docker and housekeeping](2-Docker-and-housekeeping.md): Docker with GPU access, system updates, telemetry, and the OTA check tool.
3. [Open WebUI and Ollama](3-Open-WebUI-and-Ollama.md): the first local LLM, using NVIDIA's playbook.
4. [Models and tooling](4-Models-and-tooling.md): what the models are good for, and the apps and tools that work with them.
5. [Model survey](5-Model-survey.md): four more models compared on Java, Norwegian and tool use.

Also: [Glossary](Glossary.md), for the LLM terms used in the notes, [Questions and answers](Questions-and-answers.md), for questions that came up along the way, and a [to-do list](TODO.md).
